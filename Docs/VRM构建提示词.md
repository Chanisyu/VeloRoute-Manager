# 2. v0.2 提示词
**角色设定：** 你是一个资深的 Python 桌面软件开发者，擅长处理 GIS 地理信息数据和 GUI 界面设计。

**开发目标：** 我是一个骑行爱好者，请为我开发一个运行在 Windows 上的骑行路线管理软件。

**技术栈要求：**

1. 编程语言：Python 3.x
2. GUI 框架：PyQt6
3. 地图组件：使用 `folium` 生成 HTML 地图，并通过 `QWebEngineView` 嵌入到 PyQt 界面中。
4. 数据存储：使用本地 `data.json` 文件存储所有配置和路线信息。 

**核心功能需求：**

**1. 数据结构与文件管理：**

+ 支持上传 `.gpx` 文件创建路线。
+ 每条路线包含：名称、简介、GPX 路径、总里程（自动计算）、总爬升（自动计算）、总下降（自动计算）、平均坡度、最大坡度、最小坡度、所属文件夹。
+ 支持文件夹分类管理（如：待骑行、已骑行、待徒步）。支持新建、重命名、删除文件夹和路线。

**2. 界面一：地图概览模式 (主页)**

+ **布局：** 全屏显示地图。
+ **控制面板：** 屏幕角落有一个悬浮面板，列出所有文件夹。用户可以勾选文件夹或具体路线来控制其在地图上的显隐。
+ **颜色逻辑：** 不同骑行路线使用不同颜色（例如：骑行路线1=红，骑行路线2=绿）。
+ **交互：**
    - Hover：鼠标悬停在路线上时，高亮该路线，并显示该骑行路线名称 Tooltip。
    - Click：点击具体路线，界面跳转至“界面二”。

**3. 界面二：详情与管理模式**

+ **布局：** 隐藏地图。
    - 左侧 1/3：树状结构的文件夹和路线列表（类似资源管理器）。
    - 右侧 2/3：显示当前选中路线的详细信息（名称、简介、数据统计）。
+ **功能：**在此页面可以修改路线名称、编辑简介、移动路线到其他文件夹。
+ **返回：** 必须有一个“返回地图”按钮，点击后无缝切回“界面一”。

**输出要求：** 请提供完整的 Python 代码，按功能模块封装（如 UI 类、数据管理类、地图逻辑类），并告诉我需要安装哪些 `pip` 库。
